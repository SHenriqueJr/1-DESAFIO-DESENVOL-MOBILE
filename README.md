#  Burguers — Simulador de Compras

Projeto desenvolvido como parte prática do **Desafio 1** da trilha de **Desenvolvimento Mobile** da plataforma **Mais Robotic (3ª Edição)**.

O objetivo do projeto é construir uma interface de lanchonete simulada utilizando tecnologias fundamentais da web, permitindo a interação do usuário ao calcular sub-totais e somas finais dinamicamente.

##  Tecnologias Utilizadas
- HTML5 estrutural e semântico
- CSS3 responsivo usando CSS Grid Layout e Flexbox
- JavaScript Vanilla para manipulação lógica e conversão de tipos

##  Instruções de Execução
1. Faça o clone deste repositório ou baixe os arquivos diretamente.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Clique em **"Iniciar Simulação"** para interagir com os prompts de compra do sistema.
